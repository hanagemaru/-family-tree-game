# 競走馬血統ならべ

**「ならべ」シリーズ第1弾。** 競走馬の血統をカードでつなぐ、無料・登録不要のブラウザパズルです。

## 遊び方

- **ランダム血統チャレンジ（18頭）**：競走馬データから毎回異なる親子でつながった18頭の問題を作成。
- **固定血統チャレンジ（24頭）**：サンデーサイレンスの系統を中心とした固定問題。
- 山札から補充される手札最大5枚を、場のカードにつなぐ。ドラッグまたはタップで配置できる。
- 正解できないときは2段階のヒント。いま置けない馬でも将来のつながりを知ることができる。
- 配置ごとに血統図が自動で全体表示される。ピンチ・スワイプ・拡大縮小ボタンにも対応。
- プレイ時間・ミス・ヒントを記録。進行はこのブラウザの `localStorage` に自動保存される。

## 正式公開の位置づけ

初回公開では**競走馬の2モードだけ**を表示します。以前の歴史人物（徳川家）のステージコードとデータは、将来の別の「ならべ」アプリへの展開に備えて保存してありますが、公開メニューからは選べません。

正式名称は **競走馬血統ならべ** に確定しました。公開URLと実際の本番デプロイは未設定です。

決定と公開作業：[シリーズ展開方針](docs/release-series-strategy-2026-11-14.md) ／ [リリースチェックリスト](docs/horse-release-checklist-2026-11-14.md)

## 血統データと出典

- 親子ID：Wikidata（CC0）のスナップショット。
- 母馬名：日本語WikipediaのWikibase QIDとの照合と母馬欄から補完。記事別URL・版番号を[監査データ](data/source/wikipedia-dam-evidence.v1.json)に保存。
- トウカイテイオーの母馬名の表記など、一次資料で照合した一部例外あり。
- 競走馬の個別写真は未採用。共通のベクター図柄を表示する。
- 元データの欠損は「血統不明」を意味しません。表示情報が必ずしも完全・最新であることは保証しません。

## 開発・ビルド

Node.js 22以上、Python 3。

```bash
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
npm run dev
npm run build
```

ブラウザで `http://localhost:5173` を開きます。ビルド結果は `dist/` に生成されます。公開先の静的ホスティングでは、`dist` をルートとして配信してください。ファイルを `file://` で直接開く方式はサポートしません。

## 実装構成

- `src/app.js`：UI、タッチ操作、選択・配置、自動保存
- `src/core.js`：ゲーム状態、関係判定、カメラ
- `src/random-horse-stage.js`：ランダム18頭の問題生成
- `src/diagram.js`：血統図の描画と関係線
- `src/data.js`：固定問題（徳川家の開発用データも保管）
- `data/horse-pedigree.v1.json`：ランダム問題用の元の血統データ
- `src/horse-parent-evidence.js`：出典照合済みの母馬表示情報

企画：[hanage-ideas](https://github.com/hanagemaru/hanage-ideas/blob/main/games/new-game-ideas.md) ／ 過去の開発履歴は `docs/` を参照してください。
