# 操作導線・性別配色の整理（2026-11-14）

## 目的

常設ボタンと段階的な確認を減らし、カードをつなぐという本来の操作に集中できるUIにする。
既存ステージ・ランダム出題・保存形式・得点/ヒント数の記録は変更しない。

## 変更後のルール

1. **手札選択**：カードをタップすると選択。**同じカードを再タップ**、**盤面の何もない場所をタップ**、またはEscで解除。カードを持ち上げて枠を強調し、選択中の名前だけ表示する。常設の「解除」は削除。
2. **ドラッグ**：相手のカードを明確に捉えたら、ズーム率にかかわらずその相手の**関係選択**へ直行。ドラッグを離してから相手を再指定させない。判別困難な重なり・複数候補だけを一覧にフォールバック。空白へのドロップでは一覧を勝手に開かない。
3. **意図的な直接配置**：既存の19pxマーカーと点線枠は維持。点線枠の内部にマーカーを置き250ms以上保持した場合だけ、方向から直接関係を判定。雑なドロップで偶然正解になることを防ぐ。
4. **関係の指定**：親・子・きょうだい（人物の場合は配偶者も）のボタンを1回タップで判定。旧2タップ式仮配置は復活させない。関係選択画面の「相手を変える」ボタンは削除。
5. **ヒント**：選択中のカードについてのみヒントボタンを表示。1回目はヒント1、次のタップでヒント2。ヒント枠は純粋な文章とし、「この相手を選ぶ」「答えを見て終了」などの操作ボタンは削除。降参はメニューから可能。今はつながらない手札を選んでも**勝手に他の手札に切り替えない**。
6. **その他**：常設の「相手を一覧から」「解除」を撤去。どうしても相手が押しにくい場合の一覧は、手札選択時のメニューに置く。盤面拡大はメニューへ移し、盤面には「−・全体・＋」を残す。ゲームの統計表示を「配置数・ミス数」中心に整理（時間・ヒント使用回数は結果と内部記録に残す）。

## 性別配色

- **牡**：深い青
- **牝**：落ち着いた赤紫
- **セ**：セージグリーン
- **不明**：グレー

手札・場の双方で背景・模様・性別表示を統一。色と「牡／牝／セ」の文字の二重表示で識別できるようにする。徳川ステージの配色は変更しない。

性別の情報ソース・集計は `docs/horse-usability-2026-11-13.md` を継承する。

## 検証の対象

- タップ選択→同じ手札タップによる解除→別の手札選択→配置
- 手札選択→盤面の余白タップによる解除。盤面スワイプでは解除されない
- カードへのドロップで相手を再選択させない（縮小時も同じ）
- 重なりで判定不能な場合だけ相手一覧を開く。盤面の空白では勝手に一覧を開かない
- 1回で確定する関係選択、誤配置、キャンセル、エラー表示
- ヒントの1段階目と2段階目、ヒント枠に操作ボタンなし、降参経路
- 徳川18・固定競走馬24・ランダム競走馬18の完走と復元
- 既存の偶然正解防止テスト（点線枠外・即時離しでは未配置、枠内250ms保持で直接配置）
- Chromium・WebKitのモバイル実ブラウザ検証、牡牝の計算済み背景色の差
