# 家系図ならべ：仕様と検討記録

更新: 2026-10-15

## ユーザーと合意した方針

- 高品質なゲームを目指して段階的に制作する。
- 歴史・血統の知識で挑戦し、知らなければ任意のヒントを使える。
- 初期の題材は「日本の歴史人物」と「競走馬」。
- 手札5枚から選んで置き、山札から補充する方式でまず試す。
- ソリティアのように、実際にカードをドラッグして置く。
- 固定の枠を埋めるだけでなく、カードに近づけると親・子・配偶者・兄弟へ置けるUIを志向する。
- どの人物との関係からでもつなぎたい。配置済みの系譜をスワイプして見渡し、置いた札を自動で追いかけるイメージ。
- ユーザーのUI案をそのまま再現することに拘らず、使いやすさを優先してよい。

固定枠案との比較を経て、今回の試作では自由に系譜を広げる方を先に実装。固定枠モードを永久に却下した決定ではない。

## 今回実装した試作仕様（暫定）

### 遊びの流れ

1. 徳川家（秀忠が起点）／競走馬（ディープインパクトが起点）を選ぶ。
2. 手札最大5枚を受け取る。初手は少なくとも1枚、場とつながる札を含める。
3. ドラッグ中に場のカードへ近づけると、関係の置き場所を表示する。
4. 任意の関係へドロップ。正解だけを事前に強調せず、正しい位置なら配置。不正解では札を消費せずミスを1加算。
5. 最大5枚まで山から補充する。
6. 全札を置いたら完成。時間・ミス・ヒント・手札交換回数を表示する。

札の関係は表示用の座標ではなくデータ上の関係で判定する。「家康の子」「義直の兄弟」のどちらから秀忠をつないでもよい。同一人物を重複配置しない。

### 操作

- Pointer Eventsでタッチ・マウス・ペンを扱う。HTML Drag and Dropには依存しない。
- 手札をタップして選択 → 場のカード → 関係選択でも配置できる。
- 配置済みカードを含む盤面のドラッグは、系譜全体のカメラ移動。
- 個々の配置済みカードを自由な座標に動かす機能は、今回未実装。
- ピンチ、ホイール、＋／−で拡縮。「全体」で全カードを画面内へ。
- 画面端へのドラッグ中は盤面が徐々に追従。
- 配置後は新札が安全な表示範囲に入る分だけカメラ移動する。毎回中央に戻して既存の視点を失わせない。
- 初期の枠・未配置の関係線は表示しない。
- 配置済みの座標は動かさず、新しい札を空いた同世代の位置に置く。
- 両親が場に出れば両親から子への関係線を追加する。
- 共通の親が未配置の兄弟には仮の点線を表示し、親が出たら親子線に整理する。
- Tab / Enterで札・関係を選択可能。盤面フォーカス時は矢印で移動、＋／−で拡縮、0で全体。

### 保留・ヒント・記録

- 別の保留枠は設けず、手札に置いたまま考えられる。
- 置ける札がなければ「手札を入れ替え」。手札を山の後ろへ回し、次を最大5枚引く。
- 交換後も関係のある札が手札にない場合は、山から少なくとも1枚つながる札を混ぜる。詰みを防ぐ。どの札かは表示しない。
- 山が空なら交換不可。連結した題材では残りの手札に必ず置ける札がある。
- ヒント第1段階は人物・馬の説明、第2段階は具体的な関係。各段階1回を記録。
- 時間制限・ゲームオーバーなし。単一の総合スコア式はまだ決めない。
- メニュー表示中、別タブ・アプリへ移動中は計時を止める。
- このブラウザのlocalStorageに進行を保存し、各ステージの続きから再開できる。
- ランキング、アカウント、サーバー保存、課金・広告は未実装。

## 題材

### 徳川家のはじまり（9人）

家康、秀忠、江、家光、忠長、千姫、義直、頼宣、頼房。
実親子と登場人物間の婚姻を採用する。養子・将軍継承と実親子を混同しない。全員を網羅した完全な系図ではない。兄弟姉妹には異母・異父きょうだいを含む。

主な確認先：国立公文書館「御実紀（台徳院殿御実紀）」、徳川美術館「徳川美術館について」、江戸東京博物館「江〜姫たちの戦国〜」。

### サンデーからつながる名馬（12頭）

サンデーサイレンス、ウインドインハーヘア、ディープインパクト、ブラックタイド、ステイゴールド、キズナ、コントレイル、ジェンティルドンナ、オルフェーヴル、ゴールドシップ、キタサンブラック、イクイノックス。
登録上の実父母を採用。半きょうだいを含む。馬には配偶者を設定せず、父母・産駒・きょうだいで配置する。

主な確認先：JRAの名馬紹介・競馬の殿堂・70周年サイト、JRA-VAN World、社台スタリオンステーション。各カードに出典URLを保持し、画面内から閲覧可能。

## 試遊で優先して確かめること

1. 指で札を隠していても、対象人物と関係の置き場所が分かるか。
2. 手札を選んでから場へ近づけた時、関係候補が出る距離が適切か。
3. 拡縮した時にも、カードと候補が読みやすく、別の関係へ誤って置かないか。
4. 配置後の追従が自然か。自動中央寄せの方がよい場面があるか。
5. 知らない札でも2段階のヒントが助けになるか。
6. 配置順による線の交差・兄弟の並びの分かりにくさ。
7. 手札交換が作業にならないか。枚数・保留・交換方法を変える必要があるか。

## 今後の候補（未決定）

- ソリティアらしい扇状・重なりを持つ手札表現。
- 個々のカード移動と、つながった系譜全体の移動の使い分け。
- 線の交差が多い場合の部分的な自動整列。既存の配置が大きく動く弊害との比較。
- 親・母を別々に置く候補表示、夫婦から子へつなぐ表現。
- 反復プレイ時の出題人数・起点変更・日替わり。
- 初回ガイド、ヒントの深さ、ミスの扱い。
- ステージ追加、写真・肖像の利用可否、難易度調整。
- ランキングを作る場合の出題条件統一と不正対策。
- 正式な名前、一般公開先、hanage.appとの連携。
