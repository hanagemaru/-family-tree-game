# ホーム画面再設計＋血統図の交差抑制（レビュー用・2026-11-16）

## ホーム：初回画面をゲーム開始専用にする

変更対象：`index.html`、`home-screen.css`、`src/app.js`。

- 開発者向けコピー・飾りの英語見出し・血統カードの模擬表示・重複する説明パネルを全撤去
- プレイ画面と共通の濃紺／オレンジ、斜めのタイトルバー、シンプルなゴシック体
- プレイヤーが必要とする順に、**12頭の血統を完成させよう → 初級／中級／上級 → 始める**を配置
- 難易度の短い説明は選択中だけに表示。知名度のスコアリング手法・候補上位％のような作り手の説明は表示しない
- 自己ベストは記録がある難易度だけに表示し、未プレイ時の「--:--」等は非表示
- 進行中なら「つづきから」。明示的に新しい問題へ変更する場合は再開不可を知らせて確認を取る
- 「ランキングを見る」は開始ボタンより小さく表示。「遊び方」はヘッダーに置く
- 外部サイトへ戻る導線、題材と写真の出典は補助メニュー内に移動。過去v5/v4などの未完了問題は「以前の問題」の折りたたみに残す
- プレイ時間のペナルティ説明は「遊び方」で表示。スタート画面では邪魔にならないようにする

## 血統図：無駄な交差を抑える

変更対象：`src/diagram.js`、`src/app.js`、`tests/diagram-layout-optimization.test.js`。

- これまでの家族ブロック単位の左右入れ替えに加えて、**同じ世代のカードのX座標だけを交換**する候補を探索する
- すべての候補について、見た目上の**実際の直交線の交差数**を計算し、減少を最優先、同数のときは線の合計長を短くする配置を採用
- 上下世代と行のY座標、カード間の隙間、盤面全体の幅を保つ。今回の「ヘイロー／トニービンだけの左右入れ替え」に対応する操作を追加
- 配置直後・ステージ再開・完成図に同じ最適化を適用
- **ゲームの出題生成では従来の `layoutFamily(state)` を変更せず**、表示時だけ `layoutFamily(state,{minimizeCrossings:true})` を使う。旧問題ID・カード一覧・ランキングサーバーの再現性を維持する
- 現実の血統には交差を完全に解消できない構成もあるため、無条件にゼロ交差になるとは保証しない。交差を増やす候補は採用しない
- 既存のカードのつながりと交差点の「線の切れ目」はそのまま

## テストと公開範囲

- DOMテスト：難易度切り替え・初期画面・新規／再開・出典メニュー
- Chromium／WebKitの375px・390pxスマホ画面でスクロールと操作確認
- 実データから生成したv6問題および添付画面を参考に構成した血統で、交差数・同一世代内の移動・非重複性を検証
- 本番WorkerやD1、ハブサイトは変更しない。PR #14 のプレビューで確認後、必要な調整を追加する
