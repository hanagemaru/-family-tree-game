# 検証記録

2026-10-15 / 初回試作

## 完了

- `node --check`：画面処理・ルール・データの構文確認。
- `npm test`：16テスト成功。
- 各ステージ200パターン、合計400パターンのシャッフルについて、合法手と必要な手札交換で全札を配置できることを検証。
- 札の重複・消失なし、手札5枚上限、誤配置で札を消費しないこと。
- 父母、夫婦、全きょうだい、半きょうだいからの配置。
- どこから配置しても既存札の座標が動かず、新札が重ならないこと。
- 共通の親の配置前後で、兄弟の仮線から親子線へ切り替わること。
- 保存・復元、および重複札・欠落札・不正座標・不正ヒントの保存データを拒否。
- 小型スマートフォン相当からデスクトップ相当まで、全体表示のカメラ計算。
- 新札を表示するための追従は、既に表示されている札ではカメラを動かさないこと。
- `npm run build`：静的配信物を生成。

## 未確認・制限

この実行環境では対応ブラウザ操作手段が利用できないため、ブラウザ上での描画・ドラッグ・ピンチ・iPhone実機操作は未検証。ルールの自動テストはタッチ操作の検証を代替しない。

小型画面での関係候補の重なり、文字の読みやすさ、手札の持ちやすさ、線の交差、カメラ移動の自然さを、試遊で優先確認する。
