# スポーツトレカ調UIへのデザイン変更（2026-11-14）

## デザイン方針

- AI生成モックの誇張した競馬場、ネオン、巨大ロゴ、金箔調の装飾は不採用。
- カードゲーム本来の5枚の手札・山札・家系図の配置を維持。
- マットな紙のようなカード表面と太めの日本語サンセリフ、斜めのスピードラインでスポーツトレカらしさを出す。
- ゲーム盤面は落ち着いたブルーグレー、進行表示はネイビーとオレンジ。性別は牡＝青、牝＝マゼンタ、セ＝緑のフレーム・絵の下地・ラベルで識別。
- 既存の汎用馬ベクター図を使用。**実馬を再現した写真や肖像はまだ未掲載**。写真の著作権と個体の照合が取れないまま転載・AI生成しない。

## 操作と配置

- 手札選択中だけ、対応するカードの上部に幅92px・高さ44pxの独立したヒントボタンを表示。
- 選択カードの実際の画面座標を取得し、画面端でもボタンがはみ出さないように調整。ドラッグ中は隠す。
- 文章のヒントは従来の2段階。ヒント本文に操作ボタンを入れない。場のカードやズームボタンより前面に表示。
- ヒントのボタンは手札ボタンの内側に入れず、タッチイベントを奪わない構造。
- 選択・解除、親子等の判定、点線枠で250ms保持する直接配置、山札、保存・ヒント消費は維持。
- テーマ選択・関係選択画面もゲーム画面に揃えた色と輪郭に変更。

## 検証と未対応

- Node／Pythonの既存ゲームテスト、配布ビルド、Chromium／WebKitのスマホ画面を検証。
- 5枚手札、ヒントの44pxタップ領域、選択カードとの位置関係、ヒント本文の重なり、牡牝の色差、配置時の誤操作を確認。
- 新しいCSSは配布ディレクトリにもコピーするようビルド処理を変更し、CIで存在チェック。
- 実機iPhone Safariでの操作は未確認。PC環境のWebKitテストは実機の代替ではない。
- 個体ごとの実馬写真の掲載はライセンス、著作者表示、同名馬の突合が必要なため、この変更に含めない。
- この作業はPR #7のブランチに積み上げる別PR。mainへのマージは実施しない。
