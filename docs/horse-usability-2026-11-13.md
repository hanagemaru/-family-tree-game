# 競走馬の性別と位置マーカーによる配置（2026-11-13）

## 結論

- **競走馬データ991頭すべての性別を確認**。Wikidata P21の動物用コード
  `Q44148`（雄）・`Q43445`（雌）を取りこぼしていたため、前回の「P21直接登録0件」は集計コードの誤り。
  修正・再取得後のP21は**989/991頭**。残る2頭はJRA/JBISが「せん馬」と明記するため「セ」に補完。
- トウカイテイオー（`Q11321082`）はWikidataの性別とJRA公式「競馬の殿堂」で**牡**と照合。
- すべての馬について最新時点のせん馬登録を独立監査したわけではないため、出典間の不一致があれば再点検。
- 固定24頭の既存カードも牡・牝を表示。ランダム18頭には凍結性別データを付与。出題集合とシードは不変更。

## 出典・再生成

- Wikidata P21の凍結データ：`data/source/wikidata-sex-2026-11-13.json`。再取得手順：`scripts/collect_horse_sex.py`。
- トウカイテイオー（1988年生・牡）：JRA https://www.jra.go.jp/gallery/dendo/horse23/
- ボールドブライアン（1999年生・セ）：JRA https://sp.jra.jp/JRADB/accessU.html?CNAME=sj01ude101999100620%2FAA
- エリモマキシム（1999年生・セ）：JBIS https://www.jbis.or.jp/horse/0000618990/
- 公式資料による照合結果：`src/horse-sex-official.js`。同名・異生年の誤突合を防止。
- 性別の表示は `牡 / 牝 / セ / 不明`。不明なデータを名前の印象で推定しない。

## 配置操作

1. 手札をドラッグすると、盤面では**19pxの位置マーカー**に変化し、相手のカードを隠さない。
2. 位置マーカーが場の相手カードの**上**なら「親」、**左右**なら「きょうだい」、**下**なら「子」として、点線の空のカード枠を盤面上に仮表示。仮枠は**ドラッグ中のみ**現れ、確定前には進行・ミス数を変えない。
3. 表示倍率55%以上なら、相手の上下左右の領域で指を離して**直接配置判定**。誤った関係なら選択を保持したまま関係ボタンで修正可能。
4. 相手カードの中央付近に離した場合や、手札タップ→場の相手タップの場合は、従来どおり「↑親」「↔きょうだい」「↓子」などの**関係ボタン1回タップ**で配置する。
5. 表示倍率55%未満のときは誤ターゲット防止のため、リリース後に相手カードの名前一覧を表示する。
6. ドラッグを取り消すと点線枠は消える。旧仕様の**関係選択後の2回タップ・モーダル内のミニ系譜図・半透明カードのプレビュー**は削除。
7. 点線枠は配置方向のイメージであり、正誤を先に教えない。確定後は自動整列で全体のレイアウトが動く場合がある。
