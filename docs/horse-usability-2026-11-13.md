# 競走馬カードの性別・ドラッグ・関係選択の改善（2026-11-13）

## 変更

- 競走馬カードの右上に「牡」「牝」「セ」または「不明」のラベル。手札・盤面・仮配置にも反映。
- 固定競走馬24頭は既知の性別を名前とステージ内IDの対応表で表示。
- 生成ステージは父P22・母P25として登録されていることから性別を判断。候補個体に性別の直接記載がなければ決めつけない。「不明」も明示する。
- Wikidata P21取得を991頭全てに対して実施したが、今回のデータ群では直接登録0件。生データは `data/source/wikidata-sex-2026-11-13.json` に記録。データはCC0。
- 推論で性別が得られるのは全991頭のうち328頭、名前解決済872頭のうち209頭。残り663頭は「不明」。**全馬について性別がそろったわけではない**。
- 将来JBIS/JRA等の公式情報を馬IDに突合して補完するときは、同名馬や重複個体の取り違えを検査する。

## 操作

1. 手札を場へドラッグすると、場に入った時点で大きいカードを非表示にし、小さい位置マーカーに切り替える。
2. 盤面の表示倍率が55%未満のときは、対象の誤選択防止のため、ドロップ時に必ず場のカード名一覧を表示。
3. 相手を選んだ後は、「↑親」「↔きょうだい」「↓子」（徳川ステージは「配偶者」も）から関係を選ぶ。
4. **1回目タップ:** 盤面に半透明のカードと点線の関係を表示。関係選択シート内にも見やすい小さな模式図を表示する。これだけでは進行しない。
5. **同じ選択肢を2回目タップ:** 実際の正誤判定と配置。別の選択肢をタップした場合は仮配置のみ変更。
6. 選択シートを閉じた場合、仮配置を消し、手札選択は維持する。
7. 仮配置位置は**選択した関係の方向**を示す見本。正誤を先に明かさず、確定時に全体の家系図は自動整列するため、位置が多少変わることがある。

## 互換性・検証

- 固定徳川18人・競走馬24頭・ランダム18頭のゲーム/保存形式は不変更。

- 手札・場の実イベント経路を使うDOM統合テストで2回タップ、仮配置、取消、縮小ドロップを検証。
- GitHub ActionsのNode/Pythonテストと配布ビルドで確認。Safari/iPhone実機の目視確認は別途必要。
