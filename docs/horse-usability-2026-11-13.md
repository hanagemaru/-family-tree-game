# 競走馬の性別・ドラッグと誤確定防止（2026-11-13）

## 適用済みの配置仕様

- 手札をドラッグして盤面に入れると、カードの代わりに19pxの小さな位置マーカーを表示。
- 相手カードの上にマーカーを寄せると「親」、左右は「きょうだい」、下は「子」の方向に空の点線枠を表示。これはあくまで関係の**候補**であり、正解を示唆しない。
- **単に相手カードの上・横・下で離しても配置しない。** これが以前の偶然の正解を誘発した原因。
- **直接配置の条件**：実際に表示されている**52×48pxの点線枠内**に位置マーカーを合わせ、**250ms以上**その枠内に保持してから指を離す。枠内は色が変わり、配置可能になったら「指を離してください」と表示。
- 枠外で離したり、枠内でもすぐ離した場合は、相手に対する親・きょうだい・子などを**1回タップで確定**する従来の関係選択画面へ。誤配置を推測で補完したり、操作を成功に丸めたりしない。
- 枠内から出た場合・別の相手へ動かした場合は250msの保持をリセット。取り消し・キャンセル時には枠も消す。
- 点線枠が画面外に出る、他の場のカードと重なる、曖昧な斜め方向の場合は直接配置を禁止して関係選択へ回す。フレームを無理に反対側へ移して誤った関係を暗示しない。
- **55%未満のズーム**では、点線枠は視覚ガイドとして弱く表示し、直接配置は不可。ドロップ後に対象を名前一覧から選択できる。
- 関係選択後の**2回タップ式仮配置、半透明カード、追加の確認画面**は廃止したまま。
- 元の家系図エンジン・ステージ・保存形式・ゲーム記録は変更しない。

## セルフレビューと修正履歴

1. **偶然の成功を再現**：従来の「上下左右の幅広い判定領域に離すと即配置」を廃止。正確な枠内位置＋静止時間の両方で意思を確認する。
2. **位置の曖昧さ・衝突**：カード中央、斜め方向、他カードと重なる枠、盤面端は直接確定しない。保持中に位置を外れた場合も再判定。
3. **モバイルの狭さ・ズーム**：点線枠を盤面ズームと独立した画面座標で表示。盤面高さ235pxの小画面まで枠が収まる寸法に調整。低倍率では直接配置を無効化。
4. **実ブラウザで誤操作テスト**：390×844のモバイル画面でChromiumとWebKitを操作。雑なドロップは未配置／枠内即離しも未配置／枠内保持後の確定だけ配置、の3条件を各エンジンで確認。
5. **表示と遷移の目視**：GitHub Actionsのスクリーンショットから、枠の強調、位置マーカー、配置後の300msカメラ移動を確認。移動完了前は新カードが見切れて見えるため、480ms後の可視面積を実ブラウザで検証した。保持完了時は状態メッセージを更新し、古い「相手を選んでください」が残らないよう修正。

## 性別情報（前回の対応を維持）

- 競走馬データ991頭全ての性別を表示可能。
- Wikidata P21の**動物用**コード `Q44148`（雄）・`Q43445`（雌）に対応して989頭を取得。以前「直接登録0件」となっていたのは収集プログラムの誤り。
- 残り2頭は、JRAとJBISの一次情報を確認して「セ」とした。
- トウカイテイオー（`Q11321082`、1988年生・牡）はJRA公式情報でも照合済み。
- 凍結データ：`data/source/wikidata-sex-2026-11-13.json`。再生成：`scripts/collect_horse_sex.py`。
- トウカイテイオー： https://www.jra.go.jp/gallery/dendo/horse23/
- ボールドブライアン： https://sp.jra.jp/JRADB/accessU.html?CNAME=sj01ude101999100620%2FAA
