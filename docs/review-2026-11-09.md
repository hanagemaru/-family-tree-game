# 家系図ならべ — ワンテーブルUI・ステージ拡張レビュー（2026-11-09）

## 実装方針

- プレイ画面は一枚のフェルト風テーブル。盤面と手札の間の説明・ステータス・凡例を撤去し、ヘッダー/フッターをプレイ中だけ隠す。
- 山札はカード裏面を３枚重ねた小型ビジュアルで表示。左下に置き、枚数のみ常時表示。任意の山札タップや手札交換は設けない。
- 手札５枚は山札と同じテーブルの下部に置き、選択で浮き上がる。補充時は山札の位置から飛んできたように見せる（ブラウザがWeb Animations APIを提供する場合）。
- 配置関係の選択は短い下部シート。必要に応じて相手の一覧・ヒント・盤面拡大を使う。
- 端末サイズに応じて上部の盤面が残りの高さを使い、手札領域は別枠や余白を作らない。Safari等での実表示・タッチ確認は別途必要。

## ルールのレビュー

任意の手札交換を廃止。ただし交換は以前、つながるカードが手札にない状態からの回避手段になっていた。
廃止と同時に毎回の配置後の補充に `ensurePlayable` を適用し、山札に候補が残る限り最低１枚は配置可能なカードを手札に含ませる。
既存の9枚・12枚ステージの保存データは、新規カードを山札に追加して続きから遊べるようにする。
時間・ミス・ヒント・自動保存は維持。

## ステージ追加

- 徳川家：9 → **18人**。家綱・綱吉・綱重・家宣・家継・光圀・光貞・吉宗・光友を追加。実親子のみ（将軍継承や養子縁組を親子として扱わない）。
- 競走馬：12 → **24頭**。ハーツクライ、ダイワメジャー、スペシャルウィーク、ブエナビスタ、サトノダイヤモンド、ラヴズオンリーユー、グランアレグリア、フィエールマン、ラッキーライラック、オジュウチョウサン、ソールオリエンス、ジェラルディーナを追加。
- 各追加カードの `source` に参照先を持たせた。歴史上の関係や馬の系譜は新カードも既存の起点から到達可能な範囲にした。

## セルフレビューと対応

1. **説明が盤面の邪魔**：凡例・常時説明・手札交換ボタンを撤去。操作案内はメニュー／必要な時だけの通知へ移動。
2. **盤面と手札が分離**：ゲーム中のみ全画面の単一テーブルに変更。手札を盤面にオーバーレイせず、カメラ計算が手札に隠れない構造にした。
3. **手札交換廃止による詰み**：毎回の補充に配置可能なカードの保障を追加。乱数シード200通りで自動完走を検査。
4. **ステージ拡張による系図の複雑化**：両親・交差・接続点の幾何検査を増量後の全ステージで実施。旧テストの「完全ステージでも単独の直線になる」前提は拡張後に誤りとなるため、独立した直系サブグラフで評価するよう修正。全体の交差ゼロ・カード非貫通の検査は保持。
5. **関係選択の説明が多い**：短い「AはBの…」に変更し、2×2選択ボタンの下部シートとした。

## 確認範囲と未確認

GitHub Actionsで `npm test` と `npm run build` を検証。
ただし非描画DOMテスト・静的ビルドは実ブラウザ描画を保証しない。特にiPhoneのSafe Area、手札の指による遮蔽、背景スクロール、ドラッグ後の下部シート等は実機確認が残っている。
