# UI redesign and self-review — 2026-11-08

## Scope
Reworked theme selection, header, typography, colors, card surfaces, desktop play layout, mobile hand and relation dialogs. Rules, data, diagram geometry and storage schema remain unchanged. Core/data/diagram/interaction blob hashes match the current GitHub main baseline.

## First implementation
- Unified neutral surfaces, evergreen primary actions, consistent radii, borders and typography.
- Added theme illustrations as local inline SVG and a card-connection preview; no external assets or dependencies.
- Desktop: board with a separate two-column hand panel. Mobile: board followed by all five cards.
- Added a Node development server compatible with preview host/port arguments.

## Self-review and second implementation
Reviewed actual browser screenshots at desktop and a 390 × 844 iframe viewport.
- Home actions were below the initial viewport: reduced hero and theme illustration heights and card spacing.
- Mobile hand names and actions were too small/low: increased name sizes, removed decorative card subtitles, reduced board/header height, and gave action buttons 44px height.
- Selected cards relied heavily on color: added a checkmark alongside border and position changes.
- Decorative connection lines did not align reliably with responsive cards: anchored lines and cards to the same percentage positions.
- Simplified the main introduction and removed obsolete instructions about the previous placement UI.

## Validation
- 52 existing tests passed, covering actual application event flows, both stage completions, save/restore, random deals, drag/drop, camera geometry and relation routing.
- Browser: desktop home and play screens; actual placement of Iemitsu as Hidetada's child; reload/resume.
- 390px viewport: thoroughbred title and five long card names, hint, opponent picker, relation sheet and placement of Sunday Silence as Deep Impact's parent.
- Browser console inspection found extension metadata errors, not app source errors.
- Build and Git whitespace validation passed.
- Physical iPhone/Safari touch behavior and pinch gestures were not tested; browser QA used Chromium and a mobile-width iframe, not device emulation.

User clarified a Pro Yakyu Spirits-style collectible-card feel.
