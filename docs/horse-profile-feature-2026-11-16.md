# 配置済み競走馬のプロフィール（レビュー用、2026-11-16）

## プレイヤー向け

- **場に置いたカード**をタップすると、その馬の情報を開く
- 手札を選択中に場のカードをタップした場合は従来どおり続柄選択
- 表示できるのは実際に確認した「生年・性別・写真」「主な勝ち鞍」「競走成績」「短い事実（あるときだけ）」
- 必要な情報が確認できない馬には数字や実績を捏造しない。空の「勝ち鞍」見出しは出さない
- **未配置の親子・きょうだい関係は表示しない**。従来の関係線強調は廃止（新情報がなく冗長なため）
- 閲覧にヒント・ミスの加算はない。対戦条件を揃えるため、プロフィール閲覧中も時計は進む

## データ調査

- 競走馬データ：872頭、QID単位で全件照合済み
- Wikipediaリード文：**815頭**を読み取り、勝鞍明示部分のみ抽出。加えて記事内の競走馬情報欄にある、明示された通算成績と勝ち鞍の専用テンプレートを取得
- Wikidata：優勝歴（P2522）の構造化データを照合
- 詳細の競走成績は「通算」「生涯成績」等の表記であることを確認できるときだけ収録。途中時点の勝敗を通算成績と誤表示しない
- 日本のクラシック名を含む地方独自の重賞を、同名・部分一致というだけで別のレースと誤認しない
- JRA、JBIS等の個別資料に基づく手動確認を45頭分追加（うち今回、JBISの個別ページに基づき29頭を補完）。源泉は `data/source/horse-profile-editorial-2026-11-16.json`
- **現時点で808頭に勝鞍・戦績・顕彰馬などの情報あり（872頭中約93%）**。残り64頭は確認できた基本情報のみ。未確認の記述は補わない
- 競走成績587頭、勝ち鞍615頭、紹介文60頭。Wikipedia競走馬情報欄549件を追加照合し、競走成績538頭・勝ち鞍360頭分を補強（後者は既存馬への追加も含む）
- 人気馬の主要勝ち鞍を追加で補完し、同一GⅠの複数年優勝（例：宝塚記念2013・2014）を保持。日本ダービー／東京優駿、ジャパンC／ジャパンカップなどの別名を正規化
- 情報源URLはデータに保持し、ゲーム内の「題材・出典」にまとめて表示。カードごとの出典表示はしない。Wikipediaの記事本文を長文転載せず、競走成績やレース名などの事実だけを利用
- 以前に収集したCommonsの写真371頭について、著作者・ライセンス・元画像のリンクを専用「題材・出典」画面にまとめて表示。ゲーム中の表示済みカードのみ掲載し、未登場馬のネタバレを避ける

## 出典表示の整理
- プロフィール自体は馬名・生年・性別・写真・実績・紹介（確認できた項目のみ）に限定
- 馬ごとの戦績・紹介の根拠URLは `data/horse-profiles.v1.json` と `data/source/horse-profile-editorial-2026-11-16.json` に保存
- 「題材・出典」には、配置済み馬の戦績資料と、場・手札に表示された写真の作者・元画像・ライセンスを一覧化
- 出典一覧に未登場のデッキ内の馬名を出さない。写真の表示時には画面内のメニューからクレジットへアクセス可能
- Wikipediaなどは文章転載を行わず、参照元で確認した競走実績だけを自分の文章として要約

## ピンチズームとプロフィール操作（2026-11-16）
- プロフィールの幅・画像高・余白を縮小し、閉じるボタンは同画面のみ非表示。画面外タップ・Escで閉じる
- ズームはピンチ開始時の2指の座標とカメラを基準に計算して逐次誤差を抑制
- 連続する指の移動はrequestAnimationFrameに集約。拡縮途中のSVG経路の再生成を止め、終了時に更新
- 盤面領域の寸法をジェスチャー開始時に保持し、頻繁なレイアウト参照を避ける
- 既存の手札ドラッグ、場タップによる続柄選択、ヒント・ペナルティは変更しない

## 品質保証

- 出典情報がない勝ち鞍を表示しない
- 馬のQID、出典リンク、レース名の整合性を検査
- 親子関係のネタバレ防止、エスケープ処理、手札選択時の既存操作、タイマーとペナルティを確認
- ビルドに `horse-profile.css` と `data/horse-profiles.v1.json` を含める
- Chromium／WebKitの375px・390pxでタップ操作、モーダルの表示、出典、続柄選択への影響を検査
